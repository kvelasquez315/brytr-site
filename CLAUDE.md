# Auto Commit and Push

After completing any code edit or set of edits in this project, always do the following automatically without being asked:

1. Run `git add -A`
2. Commit with a clear, specific message describing what changed
3. Push to the `staging` branch (create it if it doesn't exist yet). Never push directly to `main` or the production branch.

This should happen at the end of every edit session as standard behavior, not something the user needs to request each time.
